# MIRA project page

Project page for **MIRA: Mutual Information guided calibration for Reliable Test-Time Adaptation** (NeurIPS 2026).

**Website:** https://hyeongyu-kim.github.io/mira/

**OpenReview:** https://openreview.net/forum?id=ujUYtJK5LG
